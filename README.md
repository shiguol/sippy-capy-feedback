# 喝水卡皮 · 反馈与功能建议

[English](#english) | 中文

这里是 **喝水卡皮（Sippy Capy）** 浏览器扩展和 Android 应用的反馈中心。源码不开源，本仓库只用来收集大家的建议和问题。

- Chrome 网上应用店：<https://chromewebstore.google.com/detail/hbmmhajpienaaalopaomplofkngjfgfj>
- Android：Google Play 审核中（包名 `com.happymoon.sippycapy`）
- [隐私政策](PRIVACY.md)

## 我想要一个新功能

👉 **[提交功能建议](https://github.com/shiguol/sippy-capy-feedback/discussions/new?category=ideas)**

也欢迎先去 [功能建议列表](https://github.com/shiguol/sippy-capy-feedback/discussions/categories/ideas) 看看，如果已经有人提过，点个 👍 就行。点赞数是我排优先级的重要依据。

## 我遇到了问题 / Bug

👉 **[报告问题](https://github.com/shiguol/sippy-capy-feedback/issues/new?template=bug.yml)**

写清楚「做了什么、期望什么、实际发生了什么」，附上扩展版本号、浏览器和操作系统（提醒类问题跟系统通知设置关系很大），能帮我更快定位。

## 注意

- 提交需要一个 GitHub 账号（免费注册）。
- **这里的内容所有人都能看到**，请不要贴邮箱、手机号，也不要贴你不想公开的个人健康信息。
- 扩展的所有数据都只保存在你的浏览器里，我看不到你的使用情况。所以你的反馈对我来说非常宝贵，谢谢！

## English

This is the feedback hub for **Sippy Capy: Drink Water Reminder**, both the browser extension and the Android app. The source code is not open; this repository only collects suggestions and bug reports.

- Chrome Web Store: <https://chromewebstore.google.com/detail/hbmmhajpienaaalopaomplofkngjfgfj>
- Android: in review on Google Play (package `com.happymoon.sippycapy`)
- [Privacy policy](PRIVACY.md)

### Request a feature

👉 **[Suggest a feature](https://github.com/shiguol/sippy-capy-feedback/discussions/new?category=ideas)**

Please check the [existing ideas](https://github.com/shiguol/sippy-capy-feedback/discussions/categories/ideas) first. If someone already suggested it, just give it a 👍. Votes help me decide what to build next.

### Report a bug

👉 **[Report a bug](https://github.com/shiguol/sippy-capy-feedback/issues/new?template=bug.yml)**

Tell me what you did, what you expected, and what actually happened, plus the extension version, browser, and OS (reminder issues often depend on system notification settings).

### Please note

- You need a (free) GitHub account to post.
- **Everything here is public.** Don't post your email, phone number, or health details you'd rather keep private.
- The extension keeps all data in your browser, so I can't see how it's used. Your feedback means a lot. Thank you!
